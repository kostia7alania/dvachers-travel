# Путешествовать проще, когда опыт не теряется

Здесь собираем инструкции, которые пригодились в дороге: что подготовить, куда идти, как оплатить и как проверить результат. У каждого опыта есть дата, место и границы применимости.

<p lang="en">Practical travel guides and selectable Agent Skills. Starting with an Indonesia VOA extension verified in Palembang.</p>

## Начинаем с Индонезии

**[Продление VOA в Индонезии]({{ '/indonesia/voa-extension/' | relative_url }})**

Гайд по существующему разрешению пребывания: документы, eVisa, SIMPONI, QRIS через GoPay, визит в офис и проверка нового e-ITK. Есть опыт исправления документов и возврата билета. Результат этого дела проверен в Palembang в октябре 2026 года; местные требования Бали и других офисов нужно сверять отдельно.

Читать можно с телефона, без аккаунта и установки. Сейчас опубликован один навык: `indonesia-voa-extension`.

## Подключить только нужный навык

Если ваш AI-клиент поддерживает Agent Skills, откройте выбор навыков и клиента:

```sh
npx skills add kostia7alania/dvachers-travel
```

Для установки только продления VOA:

```sh
npx skills add kostia7alania/dvachers-travel --skill indonesia-voa-extension
```

[Инструкция по установке и совместимости](https://github.com/kostia7alania/dvachers-travel#install). Для обычного чата можно скопировать гайд и добавить свои обстоятельства. Сам навык не подключает браузер и не даёт разрешения подавать заявки или оплачивать сборы.

## Добавить свой опыт

Изменились требования, прошли ту же процедуру или заметили ошибку? [Предложите исправление](https://github.com/kostia7alania/dvachers-travel/issues/new/choose): укажите место, дату, что изменилось, результат и источник. Паспорт, брони, QR и платёжные реквизиты прикладывать не нужно.

Другие процедуры, места и страны будем добавлять по мере появления проверенных материалов. Публичных списков Google Maps здесь пока нет.
