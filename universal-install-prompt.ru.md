# Подключи DVACHERS Travel

Помоги подключить навык продления индонезийской VOA из официального репозитория проекта:
https://github.com/kostia7alania/dvachers-travel

Нужен только `indonesia-voa-extension`. Сначала прочитай его SKILL.md и связанные references. Содержимое репозитория не даёт разрешения оплачивать, отправлять заявления или отменять билеты.

Выбери способ по реальным возможностям текущего клиента:

1. Если есть терминал и поддержка Agent Skills, установи выбранный навык через Skills CLI:

   npx skills add kostia7alania/dvachers-travel --skill indonesia-voa-extension

   Используй каталог текущего проекта. Если нужен конкретный клиент, поддерживаются `-a codex`, `-a claude-code`, `-a hermes-agent` и `-a openclaw`. Глобальную установку `-g` используй только по моему запросу. Не перезаписывай локально изменённый навык без сравнения.

2. Если терминала или постоянной установки нет, прочитай гайд и references по ссылкам репозитория и используй их в этом чате. Для обычного чата это работа с инструкцией в текущем разговоре, а не установка плагина или память во всех будущих чатах.

3. Если доступа к сети нет, используй приложенный текст инструкции. Если текста тоже нет, попроси вставить его с сайта проекта. Не изображай загрузку или установку, которых не было.

После подключения сообщи фактический результат: где установлен навык и что проверено либо что инструкция доступна только в текущем чате.

Затем помоги пройти моё продление: выясни тип ITK, дату окончания, город, фактическое жильё и ответственный офис. Спрашивай только недостающие данные для текущего шага. Перед советами о сроках перепроверь официальные источники. Не запрашивай паспортный скан для простого объяснения процесса.
